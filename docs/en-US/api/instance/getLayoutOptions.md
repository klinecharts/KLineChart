# getLayoutOptions()
`getLayoutOptions` gets the chart's current complete default layout configuration.

## Reference {#reference}
<!--@include: @/@views/api/references/instance/getLayoutOptions.md-->

### Parameters {#parameters}
`getLayoutOptions` does not accept any parameters.

### Returns {#returns}
`getLayoutOptions` returns the complete layout configuration `Layout`, including the bar space limits, default pane options, and default y-axis options.
